Ultra-Low Latency WebRTC Stream (<0.5s)

Powered by go2rtc. Solves video delay and buffering lag completely by streaming native H.264/H.265 via WebRTC with zero re-encoding overhead. Latency is under 500ms (true real-time). Any modern browser negotiates SDP directly with this API.

POST http://110.232.92.134:3001/api/webrtc
Request / Response Specification
Field Type Description
Content-Type string application/sdp
Request Body string Raw SDP offer created by client RTCPeerConnection
Response Body string Remote SDP answer for pc.setRemoteDescription() 
// WebRTC client integration in React, Vue, or Vanilla JS:
const pc = new RTCPeerConnection({
  iceServers: [{ urls: 'stun:stun.l.google.com:19302' }]
});
pc.addTransceiver('video', { direction: 'recvonly' });

pc.ontrack = (event) => {
  const videoEl = document.getElementById('my-video');
  videoEl.srcObject = event.streams[0];
};

const offer = await pc.createOffer();
await pc.setLocalDescription(offer);

const res = await fetch('http://110.232.92.134:3001/api/webrtc', {
  method: 'POST',
  headers: { 'Content-Type': 'application/sdp' },
  body: offer.sdp
});
const answerSdp = await res.text();
await pc.setRemoteDescription({ type: 'answer', sdp: answerSdp });
# Send raw SDP offer to exchange peer connection:
curl -X POST http://110.232.92.134:3001/api/webrtc \
  -H "Content-Type: application/sdp" \
  --data-binary @offer.sdp

GET http://110.232.92.134:3001/api/snapshot
Response Specification
Header / Type Value Description
Content-Type string image/jpeg
Content-Disposition string inline; filename=snapshot.jpg

Get Stream Telemetry & Status

Returns real-time telemetry from the gateway background capture thread, including measured framerate (FPS), video resolution, reconnect count, and ONVIF handshake status.

GET http://110.232.92.134:3001/api/status
Response Attributes
Property Type Description
status string "online" or "offline" based on active incoming video frames.
connected boolean Whether the background RTSP capture connection to 10.10.1.17:554 is active.
measured_fps number Actual measured frames per second received from the camera stream.
resolution string Dimensions of the video stream (e.g. "1280x720").
onvif_connected boolean Status of ONVIF service handshake on port 2020. 
curl http://110.232.92.134:3001/api/status
const res = await fetch("http://110.232.92.134:3001/api/status");
const data = await res.json();
console.log(`Camera status: ${data.status}, FPS: ${data.measured_fps}`);

PTZ Continuous Move

Controls camera physical orientation and optical zoom. Sends continuous Pan, Tilt, and Zoom velocity commands to the camera via ONVIF PTZ service. Speeds range from -1.0 to 1.0.

POST http://110.232.92.134:3001/api/onvif/ptz/move
Request Body (JSON)
Field Name Type Range Description
pan float -1.0 to 1.0 Horizontal movement speed. Negative values pan Left, positive values pan Right.
tilt float -1.0 to 1.0 Vertical movement speed. Negative values tilt Down, positive values tilt Up.
zoom float -1.0 to 1.0 Optical zoom velocity. Negative values Zoom Out, positive values Zoom In. 
# Pan right at 50% velocity
curl -X POST http://110.232.92.134:3001/api/onvif/ptz/move \
  -H "Content-Type: application/json" \
  -d '{"pan": 0.5, "tilt": 0.0, "zoom": 0.0}'
// Pan Left in JavaScript
await fetch("http://110.232.92.134:3001/api/onvif/ptz/move", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ pan: -0.5, tilt: 0, zoom: 0 })
});

PTZ Stop Movement

Immediately halts all ongoing Pan, Tilt, and Zoom motion on the camera. Always call this endpoint after triggering a continuous move.

POST http://110.232.92.134:3001/api/onvif/ptz/stop

Transparent ONVIF SOAP Proxy

Transparent reverse-proxy for full ONVIF SOAP XML requests. Any external Video Management System (VMS), Synology Surveillance Station, or ONVIF Device Manager software can point directly to this gateway on port 3001 to interact with the camera via native ONVIF protocol without a VPN.

POST http://110.232.92.134:3001/onvif/{service}
VMS Connection Settings
Parameter Value
ONVIF Host / IP 110.232.92.134
ONVIF Port 3001
Path /onvif/device_service or /onfiv/device_service
Username NMSIOTYOGYA1
Password Nayaka2025 
# Sample raw SOAP GetDeviceInformation call:
curl -X POST http://110.232.92.134:3001/onvif/device_service \
  -H "Content-Type: application/soap+xml; charset=utf-8" \
  -d '<?xml version="1.0" encoding="utf-8"?><soap:Envelope xmlns:soap="http://www.w3.org/2003/05/soap-envelope" xmlns:tds="http://www.onvif.org/ver10/device/wsdl"><soap:Body><tds:GetDeviceInformation/></soap:Body></soap:Envelope>'
