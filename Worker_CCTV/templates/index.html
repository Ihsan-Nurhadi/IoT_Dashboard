🚀 Ready-to-Use Public API Endpoints
Buka Swagger UI (Coba API)
Method Endpoint Fungsi / Kegunaan Contoh Integrasi
GET /api/stream Live video stream (MJPEG multipart). Langsung ditonton di browser/dashboard. <img src="http://IP_VPS:3001/api/stream" />
GET /api/snapshot Mengambil 1 frame foto JPEG terbaru beresolusi penuh secara instan. fetch('/api/snapshot').then(r => r.blob())
GET /api/status Status kesehatan koneksi RTSP, resolusi, FPS terukur, dan error log. curl http://IP_VPS:3001/api/status
GET /api/onvif/device-info Informasi perangkat dari ONVIF (Manufacturer, Model, Firmware, Serial). curl http://IP_VPS:3001/api/onvif/device-info
GET /api/onvif/profiles Daftar profil encoding video yang didukung oleh kamera. curl http://IP_VPS:3001/api/onvif/profiles
POST /api/onvif/ptz/move Menggerakkan kamera Continuous Move (Pan, Tilt, Zoom speed). {"pan": 0.5, "tilt": 0.0, "zoom": 0.0}
POST /api/onvif/ptz/stop Menghentikan pergerakan kamera PTZ seketika. POST /api/onvif/ptz/stop
POST /onvif/{service} Transparent SOAP Proxy untuk VMS luar (seperti ONVIF Device Manager). Arahkan ONVIF Client ke http://IP_VPS:3001
